# 用户用例与验收

| 编号 | 场景 | 必须证明 |
| --- | --- | --- |
| B-01 | 只读十章中的两章 | 未读保持未读，覆盖按固定输入字节并集计算 |
| B-02 | 重叠分块、空范围与混合换行 | 不双重累计，合法UTF-8边界，空文本不虚构覆盖 |
| B-03 | 参考小说和自己的原稿 | 仅分析固定来源，参考正文不变为正式章节 |
| B-04 | 场景、信号与读者视角 | 所有关联可定位，读者反应明确是分析假设 |
| B-05 | 新稿修改一章 | 仅预览影响，不重写旧分析；关联依赖有说明 |
| B-06 | 中途失败后继续 | 成功与失败分块分别回读，不把任务创建当完成 |
| B-07 | 问题标为已处理 | 必须有新来源和复核说明，候选存在不等于解决 |
| B-08 | 分析交给审校与续写 | 固定依据可回读，原文、意见及采纳仍由Core负责 |
| B-09 | CAS、同键重放和响应丢失 | 保留旧修订，原键恢复，不重复写入 |
| B-10 | 同一连接安装、启停、卸载重装 | 动作和Skill动态发现，数据仍可回读 |
| B-11 | 恶意HTML、中文长段、窄窗和键盘 | 离线输出转义，工作面可读且无横向溢出 |
| B-12 | 旧版本与外部副作用 | 不因专业保存采纳正文、改设定、定稿或付费 |

单元验证不变量和专业反例，真实CLI/MCP验证所有动作、固定来源、跨作品隔离、CAS及恢复，Electron验证作者工作面、固定导出、浅暗、窄窗、键盘及重开；当前Codex会话发现独立取证。发布制品、跨平台与作者实际质量判断分别验收，不以测试数量替代。
